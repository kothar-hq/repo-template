# Architecture Decision Records

This directory records significant decisions made in this project. Each ADR
captures the context, the decision, and the consequences so future contributors
can understand why the project is the way it is.

To add an ADR, copy the template below or use the `adr` Claude Code agent.
Number files sequentially from `0001` with no gaps.
